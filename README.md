# TraceView（波形読取ツール）

紙に記録された地震計などの波形（ラスターPDF・画像）から、波形ごとの**最大値・最小値とその位置**を読み取り、
**元画像と照合しながら確認・修正して Excel に出力**するデスクトップアプリです。

- 画像処理・再追跡・保存・出力はすべて**端末内**で行います（AIモデル・外部API・クラウド・オンライン認証は使いません）。
- 元ファイルは変更しません。
- 要件定義書（v1.0 / 2026-10-29）の必須要件に沿って作っています。

> **現在の状態（v0.1.0）**: 自動読取の精度は未達です。三段の取得・頂点の抽出までは動きますが、
> 隣の段への迷い込み、汚れの取り込み、右側の未追跡が残ります。これらは「要確認」として画面に示し、
> 人が確認・修正する前提です。「確認済み」にするまで、数値は**候補**として扱います。
> Windows 実機での動作は、まだ確認していません（開発・試験は Linux）。

画面例は [docs/screens](docs/screens) にあります。

## 1. 起動のしかた

| 方法 | 手順 |
|---|---|
| exe（配布版） | `TraceView.exe` を起動（作り方は [docs/WINDOWS配布.md](docs/WINDOWS配布.md)） |
| ソースから | `pip install -r requirements.txt` のあと `python app.py`（Windows は `run_windows.bat`） |
| ファイルを開いて起動 | `python app.py 波形.pdf` ／ `python app.py 作業.trproj` |
| 環境の自己診断 | `python app.py --selftest`（画面なし・通信なし。結果は `selftest_result.txt` にも出力） |

必要なもの: Python 3.11 以降（開発・試験は 3.13）、Windows 10/11 64bit を想定（**仮置き**。要確認事項⑤）。

## 2. 標準の使い方

1. **開く**: PDF・画像を開く（PDF/TIFF は「ページ」で選択）。
2. **自動解析**（F5）: 三段の起点と波形を自動取得し、元画像に段ごとの色で重ねる（約20秒）。
3. **照合**: 先端・折返し・末端を画像と見比べる。「要確認」タブの項目をダブルクリックすると該当位置へ移動。
4. **修正**: 必要な頂点だけ、ドラッグで移動／「頂点を追加」で追加。その先が自動で再追跡される。
5. **測定線・校正**: 0・上・下の線（上下にだけ動く）と、必要なら「校正」タブを確認。
6. **確認して出力**: 「確認済みにする」→「作業を保存」→「Excel出力」。

### 記録方式の選び方（機種が分からないとき）

記録方式（インクペン・煤書き・光学など）によって、線の見え方や必要な処理が変わります。
機種が分からない図面では、**「方式を探す…」**（F6）を押すと、設定（プロファイル）を数種類順に試し、
重ね表示の縮小画像を横並びで表示します。元画像に重なって見えるものを選んでください。

| プロファイル | 想定 | 検証状況 |
|---|---|---|
| ① レバー式インクペン | 明るい紙に暗い線、大振幅が円弧状。時刻の刻み・小さな黒い印を除外 | サンプルB1-01のみ確認 |
| ② 明暗反転 | 暗い紙に明るい線（煤書きなど）。画像を反転して解析 | **未検証**（見本なし） |
| ③ 太い線・にじみ | 感光紙・光学など。弱い線も拾い、小さな欠けを埋める | **未検証**（見本なし） |
| ④ 汎用 | 方式が不明なときの標準設定 | サンプルB1-01のみ確認 |

- 候補に付く数値（末端まで追跡できた段数・未追跡の長さ・要確認の数）は、**うまくたどれたように見えるかの目安**で、正しさの保証ではありません。最終判断は画面で拡大して行ってください。
- 4種類の試行には、この環境（Linux）で約70秒かかりました（サンプル画像）。お使いのPCでは変わる可能性があります。
- 選んだ設定は作業ファイルとExcelに記録されます。ツールバーの「記録方式」でも、後から切り替えられます（解析をやり直します）。

### 区間測定（範囲を決めて、振れ幅・波の数・周期を調べる）

横軸が時間の記録では、時間の範囲を決め、その間の振れ幅（最大・最小）、波の数、周期を調べます。

1. 「区間を指定」(R) で、画像上を**横にドラッグ**（選択中の段に追加）。数値入力でも追加できます（「区間」タブ）。
   「全段に同じ範囲を追加する」で、三段同じ範囲を一度に追加できます。
2. 「区間」タブに、区間ごとの結果が出ます。区間は戻す（Ctrl+Z）・削除できます。
3. Excel の「区間測定」シートに出力されます。

| 項目 | 定義 |
|---|---|
| 最大・最小・上下幅 | 区間内の頂点から（0線を基準） |
| 山の数・谷の数・波の数 | 「数え方の設定」で選ぶ（山／谷／山と谷の平均）。隣の頂点との振れ幅が**数えない小さな揺れ[px]**未満の揺れは数えない（既定20px） |
| 平均周期 | 最初の山から最後の山までの距離 ÷（山の数−1）。山が2個未満のときは出さない |
| 周波数 | 1 ÷ 平均周期[s]（時間換算があるときだけ） |
| 除外した頂点 | 所属要確認の区間・推定接続の区間上の頂点は、最大・最小と波の数から除外し、件数を表示 |

**時間の与え方（資料がなくても設定できます）**: 「校正」タブで、次のどちらかを設定します。

- 紙送り速度[mm/s]＋X方向の校正（定規2点）
- 「時刻の刻み2点で時間を設定」: 画像上の時刻の刻みを2か所クリックし、その間の時間[秒]を入力

どちらも未設定のときは、周期は px 表示です（時間は出しません）。画面上の復元順の再生は、時間とはみなしません。

### 円弧補正（レバー式ペンの時間方向のずれ）

レバー（アーム）の先端で書くペンは、振幅が大きいほど、時間方向（X）の位置が円弧の分だけずれます。
「校正」タブで、**X・Yの校正**と**ペンアーム長[mm]**を入力すると、Excelに「円弧補正後のX[mm]」の列が追加されます
（さらに紙送り速度があれば「補正後Xからの時間[s]」）。ずれの向きは、記録機構によって異なるため利用者が選びます。
アーム長は推定せず、**入力がなければ補正しません**。補正式は `x' = x − 向き × (R − √(R² − a²))`（R: アーム長、a: 振幅[mm]）です。

### 画面の構成

- 上: ツールバー（ファイル／編集／表示）。
- 中央: 元画像＋トレースの重ね表示。ホイールで拡大縮小、ドラッグで移動。
- 右: 段の一覧（色・表示切替）と、**測定／頂点／要確認／校正**のタブ。
- 最下部: 読込・解析・再追跡・保存の状態、読取確認の進み具合、カーソルの座標。

### 操作一覧

| 操作 | 方法 |
|---|---|
| 頂点の移動 | 「選択・移動」(S) で頂点をドラッグ。または「頂点」タブで座標入力→「座標を反映」 |
| 頂点の追加 | 「頂点を追加」(A) で取り逃した先端をクリック。先端まで到達して折り返す経路が追加される |
| 再追跡 | 既定は移動後に自動。オフにすると保留され、「再追跡を適用」(Ctrl+Enter) で実行 |
| 修正の取消し | 「修正を取り消す」(Esc)＝未適用の修正を破棄 |
| 戻す／やり直す | Ctrl+Z / Ctrl+Y（段ごと）。「この段を初回結果へ」で段単位に初期化（他の段は変更しない） |
| 起点の指定 | 自動で起点が見つからない段で「起点を指定」(O)→波形の左端をクリック |
| 測定線 | 0線・上線・下線を上下にドラッグ（手動調整は「（手動）」と表示。「自動位置へ戻す」で復帰） |
| 校正 | 「校正」タブ。定規上の2点＋実距離、または数値入力。X・Y・紙送り速度・振幅係数 |
| 再生 | 「再生」(Space) で復元順に経路を再生。「頂点▶」「◀頂点」で頂点を順に移動 |
| 表示切替 | 元画像／トレース／頂点／測定線／要確認印、段ごとのチェック。頂点・弱い要確認印は拡大時のみ表示 |

修正が失敗した場合（指定位置の近くに画像の線がない、線がつながらない、など）は、理由を表示して**修正前の結果を保持**します。
未適用の修正がある間は、Excel・SVG の出力を止めます。

## 3. 出力

### Excel（.xlsx）

| シート | 内容 |
|---|---|
| 測定結果と画像 | 段別の測定値、0・上・下の高さ、線の調整状態、確認状態、換算条件、元画像と重ね表示画像 |
| 復元座標 | 段・復元順・X・Y・振幅・区分（自動取得／推定接続／手動頂点／再追跡）。経路は形を保つ範囲で間引き、頂点は必ず含む |
| 頂点と折返し | 頂点番号・座標・山/谷・往路/復路・折返しの種類・対応する復元順・由来・要確認事項 |
| 要確認 | 所属の曖昧さ、末端の未追跡、推定接続、他の段への逸脱、再追跡の失敗 |

「確認状態」が「確認済み」以外の値は**候補**です（確定した最大・最小値として扱わないでください）。

### その他

- **トレースのみ（SVG）**: 各段を1本の経路として出力。推定接続は破線。元画像を含めるか選べます。
  トレースのみでも、匿名化済みとは限りません。
- **作業ファイル（.trproj）**: 経路・頂点・測定線・校正・確認状態・手動修正・履歴を保存し、別の日に再開できます。
  元ファイルの識別情報（SHA-256）を持ち、**別の原本には適用できません**。

## 4. 座標と計算の定義

- 座標: 元画像の左上が原点、X は右向き、Y は下向き（px）。解析は縮小画像で行い、出力は元画像の座標へ戻します。
- 振幅: `a = y0 − y`（0線より上が正）。y0 は各段の起点付近の高さ。
- 最大値・最小値: 頂点の a の最大・最小。位置（X・Y）を対で出力。
- 上振幅 = max(0, 最大値)、下振幅 = max(0, −最小値)、上下幅 = 最大値 − 最小値。
- 「連続する頂点間の最大差」は**参考値**として別に出力（要確認事項①）。
- 他の段の領域へ伸びる区間上の頂点は、最大・最小の対象から外し、件数を表示します。
- 未校正では px 表示。校正すると mm、さらに振幅係数を設定するとその単位で表示。紙送り速度の設定がない限り時間は出力しません。

## 5. 仮置きした事項（要件定義書の「要確認」）

| 事項 | 今回の仮置き |
|---|---|
| ① 最大差 | 上下幅（最大値−最小値）を主、連続頂点間の最大差を参考列 |
| ② 測定範囲 | 段全体 |
| ③ 換算条件 | 未校正は px。校正は利用者入力 |
| ④ 許容誤差・評価原稿 | 未設定（正解データが未提供）。試験は合成シートで実施 |
| ⑤ Windows版・配布方法 | Windows 10/11 64bit、PyInstaller の onedir 形式（フォルダ配布） |
| ⑥ 画像のない位置の手動点 | 対象外 |
| ⑦ 記録方式 | 利用者が選ぶ。不明なときは「方式を探す」で数種類を試して選ぶ（自動判定はしない） |

## 6. 既知の制限

- 自動読取の精度は未達（頂点の取りこぼし、隣の段・汚れへの迷い込み、細線が切れた先の未追跡）。
- ②③の記録方式プロファイルは、見本がないため未検証。円弧補正の向き・アーム長は利用者入力に依存。
- 傾き補正・回転補正は未実装（変換情報の保存枠のみ）。複数ページの一括処理、三段以外の本数も対象外。
- Windows 実機での動作・Excel の実機表示は未確認。

## 7. 開発者向け

```
traceview/
  imageio.py     読込（PDF/画像、原本は変更しない）
  preprocess.py  紙領域・定規・基準線・注記の除外、インク抽出
  graph.py       骨格 → グラフ（端点・分岐・辺）、途切れの補修
  tracer.py      ペンの経路をたどる（先端へ到達→折返し、往復、分岐の判断）
  vertices.py    経路に沿った山・谷の抽出
  engine.py      解析全体、頂点の移動・追加と再追跡、戻す／やり直す
  measure.py     測定値・校正
  project.py     作業ファイル  excel_out.py / svg_out.py  出力
  profiles.py    記録方式プロファイル（設定の組）
  gui/           PySide6 の画面（方式の比較画面を含む）
tests/           合成シートを使った試験（python -m pytest tests）
```

試験の限界: 合成シートでの合格は、実データの精度合格を意味しません。実データでは正解の頂点・所属を基準に別途評価してください。
