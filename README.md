# TraceView（波形読取ツール）

紙に記録された地震計などの波形（ラスターPDF・画像）から、波形ごとの**最大値・最小値とその位置**を読み取り、
**元画像と照合しながら確認・修正して Excel に出力**するデスクトップアプリです。

- 画像処理・再追跡・保存・出力はすべて**端末内**で行います（AIモデル・外部API・クラウド・オンライン認証は使いません）。
- 元ファイルは変更しません。
- 要件定義書（v1.0 / 2026-10-29）の必須要件に沿って作っています。

> **現在の状態（v0.1.0）**: 自動読取の精度は未達です。三段の取得・頂点の抽出までは動きますが、
> 隣の段への迷い込み、汚れの取り込み、右側の未追跡が残ります。これらは「要確認」として画面に示し、
> 人が確認・修正する前提です。「確認済み」にするまで、数値は**候補**として扱います。
> Windows 実機での動作は、まだ確認していません（開発・試験は Linux）。

画面例は [docs/screens](docs/screens) にあります。

## 1. 起動のしかた

| 方法 | 手順 |
|---|---|
| exe（配布版） | `TraceView.exe` を起動（作り方は [docs/WINDOWS配布.md](docs/WINDOWS配布.md)） |
| ソースから | `pip install -r requirements.txt` のあと `python app.py`（Windows は `run_windows.bat`） |
| ファイルを開いて起動 | `python app.py 波形.pdf` ／ `python app.py 作業.trproj` |
| 環境の自己診断 | `python app.py --selftest`（画面なし・通信なし。結果は `selftest_result.txt` にも出力） |

必要なもの: Python 3.11 以降（開発・試験は 3.13）、Windows 10/11 64bit を想定（**仮置き**。要確認事項⑤）。

## 2. 標準の使い方

1. **開く**: PDF・画像を開く（PDF/TIFF は「ページ」で選択）。
2. **自動解析**（F5）: 三段の起点と波形を自動取得し、元画像に段ごとの色で重ねる（約20秒）。
3. **照合**: 先端・折返し・末端を画像と見比べる。「要確認」タブの項目をダブルクリックすると該当位置へ移動。
4. **修正**: 必要な頂点だけ、ドラッグで移動／「頂点を追加」で追加。その先が自動で再追跡される。
5. **測定線・校正**: 0・上・下の線（上下にだけ動く）と、必要なら「校正」タブを確認。
6. **確認して出力**: 「確認済みにする」→「作業を保存」→「Excel出力」。

### 通る道を大まかに描く（線の取り違えを防ぐ）

波形が通る**おおよその道筋**を描くと、その道に沿った線を優先してたどります。どちらへ進むか迷う所（交差・接触・近くに並ぶ別の線）で、描いた道に近いほうが選ばれます。

1. 右パネル「段の確認」タブの **①-b「通る道を、大まかに描く」** で「道を描く（クリックで点を打つ）」を押す。
2. 画像上を、**左から右へ、数か所クリック**（青い点線で表示。「最後の点を消す」「描き直す」、Esc でやり直し）。取り違えやすい所だけでもOKです。
3. 「道の幅 [px]」（既定40px。道から、どれくらいまでの線を「沿っている」とみなすか）を決めて、**「この道に沿って引き直す」**。
4. 道は、段の色の帯で画像に残ります。「道を消して引き直す」で外せます。戻す(Ctrl+Z)でも戻せ、作業ファイルに保存されます。

- 描いた道の範囲（横方向）の外には、影響しません。
- **道から遠い線**（幅の3倍、または120pxのうち大きいほうより離れた線）は、道の範囲内では、たどりません。
- **道から突き出る尖った波**（先端が遠くても、根元が道の近くにあるもの）は、これまでどおり、先端まで追跡されます。
- 道はヒントです。道の近くに線がなければ、線は作られません（画像にない線は、引きません）。
- 編集中の段にだけ働き、ほかの段には影響しません。

### 編集中の段だけを動かす（ほかの色の線に影響しない）

赤い線（上段）を編集しているときは、**ほかの色の線（中段・下段）には、一切影響しません**。

| 仕組み | 内容 |
|---|---|
| ロック（既定オン） | ツールバーの「編集中の段だけ動かす」。いま選んでいる段（例：赤の上段）の点・線・測定線だけが操作できます。**ほかの段は薄く表示され、クリックもドラッグもできません**（重なって見えても、選んだ段の点が優先されます）。右上の段の一覧で段を選ぶと、ロックの対象が、その段に移ります。「点の編集」タブの先頭に、「編集中の段」と「ほかの段はロック中」が表示されます |
| 線を、ほかの段の線に乗せない | 点を動かすときの経路は、**ほかの段の線を避けます**（避けて通れないときだけ通ります）。点は、ほかの段の線の上に吸着せず、ドラッグでも、そこへは行けません |
| 除外範囲 | 囲んだ範囲に、ほかの段の線もかかるときは、確認が出ます。進めると、**引き直すのは編集中の段だけ**で、ほかの段は、いまの線のままです（要確認に「除外範囲に、この段の線がかかっています」と印が付き、必要なら、その段を選んで引き直せます） |
| 保証していること | 点の移動・追加・削除、線の一部を消す、範囲の指定、検証と引き直しは、**編集中の段だけ**を変えます（自動試験で確認） |

ロックを外すと（チェックをオフ）、どの段も編集できます。

### 点の編集モード（「点の編集」タブ）

ツールバーの**「点の編集」(S)** が、点を直すための、管理された編集モードです（右パネルの「点の編集」タブに、状態と操作が出ます）。

| 操作 | 内容 |
|---|---|
| 選ぶ | 点をクリック＝**その1点だけ**を選択（黄色の輪）。Ctrl（Shift）+クリック＝追加・解除（水色の輪）。空いた所をドラッグ＝**枠で選ぶ**。Esc＝解除。選択中の点の数と一覧が、タブに出ます |
| 動かす | 点をドラッグ。**動くのは、つかんだ1点だけ**です（ほかの選択した点は動きません）。点は画像の線の上だけを動きます |
| プレビュー | 動かすと、すぐには変えず、**プレビュー**を表示します（もとの線＝灰色の点線、新しい線＝緑）。変わる線の長さ（px）と頂点数の変化も出ます |
| 適用／取消 | 「適用」(Ctrl+Enter) で確定、「取消」(Esc) でやめます。できない修正は、理由を表示して、自動で取り消します |
| 引き直し方 | 「この点の前後だけ引き直す」（既定。短い区間だけが変わり、ほかの線は変わりません）／「この点から先を、すべて引き直す」 |
| 削除 | Delete（Backspace）。**選んだ点をまとめて削除**（戻す(Ctrl+Z)は1回で全部戻ります） |
| 線の一部を消す | 「線の一部を消す」(X) で、消したい所を四角で囲む → 消される部分が**赤い点**で出る → 「消す」で確定（Escでやめる）。トレース線に切れ目ができます（画像の線そのものは変わりません）。あとで線を引き直しても、消した所は消えたままです。要確認に「手動で消した区間」と出ます |

「動かしたらすぐ適用」（ツールバー）をオンにすると、プレビューなしで、すぐ適用します（既定はオフ）。

> 以前、点を動かすと「まとめて変に動く」ことがありました。原因は、①Qtの機能で、選択した複数の点が一緒に動いていたこと、
> ②点を動かすと、その点から先の線がすべて引き直されること、の2つでした。どちらも、上の仕組みで対処しています。

### 途切れの先まで点を連れていく（延長線上の線へ）

線が途切れていて、その**延長線上に線がある**とき、点を、途切れを越えて、その線まで連れていけます。

- トレースの**末端**には、白い丸の**「末端ハンドル」**があります。これをドラッグして、途切れの先にある線の上まで動かします。
- ドラッグ中、点は画像の線の上だけを動きますが、途切れの端で、**線が向いている方向（延長線上）の約300px以内**にある別の線があれば、そちらへ乗り移れます。そのとき、端から着地点まで**オレンジの破線**が出ます。
- 離すと、プレビュー（緑）が出ます。「適用」(Ctrl+Enter、または画像エリアで Enter) で確定すると、そこから先が追跡されます。
- 手でつないだ区間は、**推定接続（黄色の破線）**として記録され、「要確認」に長さ付きで出ます。最大・最小・波の数からは除外されます。
- 途中の点（頂点）も、同じように、途切れを越えて動かせます。離れすぎている・延長線上にない場合は、理由を表示して、何も変えません。
- 「線に沿って動かす」をオフにすると、この制限なしに、自由に動かせます。

### 除外の候補（グラフと関係ない線・汚れを、解析の前から外す）

- 「除外」タブの**「除外の候補を探す」**（**解析の前でも使えます**）: 汚れ（濃くて大きなしみ）と、文字・書き込み（小さな印の集まり）を、目安で探し、画像に点線の四角（橙＝汚れ、紫＝文字・書き込み）で表示します。
- 画像で確かめて、候補にチェックし、**「チェックした候補を除外に追加」**。解析の前なら、記憶だけして、「自動解析」で反映されます（一度に複数追加しても、引き直しは1回です）。
- グラフの線の近く（各段の基線の周り）は、候補にしません。線から飛び出した波の先端は、候補になりません。
- 見つからないものは、「除外範囲を囲む」(E) で、解析の前から、手動で囲めます。
- 候補は目安です。**間違って候補になることも、見逃すこともあります**。必ず画像で確かめてください。

### 段ごとに確認する手順（「段の確認」タブ）

「一段ずつ順番に解析」にチェックして「自動解析」すると、右パネルの先頭に**「段の確認」タブ**が開きます。
1段ずつ、**①→⑤の順**に進めます。

| 手順 | 内容 |
|---|---|
| ① 線が通る上下の範囲を選ぶ | 「画面で上から下へドラッグして選ぶ」（横の位置は関係ありません）。または上端・下端のY[px]を数値で入れて「数値を反映」。範囲は画像に、段の色の帯で表示されます |
| ② 範囲まで線が届いているか確認 | 範囲を選ぶと**自動で確認**します（「範囲の線を確認」ボタンでも可）。起点が範囲の中にあるか、上端・下端まで現在の線が届いているか、その近くに線の先端が何本あるか、範囲の外に出る線がどれだけあるか、を ◯／×／△ で表示 |
| ③ この範囲で引き直す | 「この範囲で引き直す」。範囲の外が中心の線は使われません（範囲から少し突き出る線は使われます）。戻す(Ctrl+Z)で元に戻せます。「自動の範囲に戻す」で元の範囲に戻せます |
| ④ 結果を見て直す | ずれた頂点はドラッグ、取りこぼした先端は「頂点を追加」、文字・汚れは「除外範囲を囲む」、全体の点検は「検証して引き直す」（タブ内にボタンと説明があります） |
| ⑤ 確認済みにして次の段へ | 「確認済みにして次の段へ」。この段を確認済みにして、次の段を解析します（確認済みの段の線は、あとの段が使いません） |

- 範囲に起点（左端の線）が入っていない場合は、引き直しを拒否し、何も変えません。
- 範囲は作業ファイルに保存されます。

### 一段ずつ順番に判定する（線の取り違えを減らす）

三段は、いっぺんにではなく、**上段から順に**判定します。**先に判定した段が使った線は、あとの段が使いにくくなります**
（隣の段の線を取り違えにくくなる）。さらに、確認しながら進めるモードがあります。

1. ツールバーの「一段ずつ順番に解析」にチェックして「自動解析」→ **まず上段だけ**を解析します（残りの段は「未解析」）。
2. 上段を確認・修正し、「確認済みにする」。
3. 「次の段を解析」(F8) → 中段を解析します。**確認済みの段の線は、使いません**（使わないと末端まで追えない場合だけ、線の共有を許し、「確認済みの段と線が重なる」と要確認に表示）。
4. 同様に、下段へ進みます。
5. 上の段を直したあとは、「後の段を引き直す」で、それより下の段を、直した線を避けて引き直せます（戻す(Ctrl+Z)で戻せます）。

- チェックを入れずに「自動解析」すると、上段から順に、まとめて解析します（確認済みの段はまだないので、先の段の線を避けるだけです）。
- 効果は、図面によります。サンプル画像では、段どうしが共有する線の数が少し減った程度（14→12、19→18）でした。**取り違えがなくなることは、保証できません**。

### 除外範囲（文字・汚れが線につながっているとき）

文字や汚れが波形の線につながって、線として取られてしまうときは、**その部分を四角で囲んで除外**します。

1. ツールバーの「除外範囲を囲む」(E) を押し、除外したい所（文字など）を、画像上で**ドラッグして囲む**。
2. 囲んだ中の線は使われなくなり、線が通っていた段だけが**自動で引き直されます**（他の段・他の段の修正は変わりません）。
3. 「除外」タブに一覧が出ます。選んで削除すると、その範囲の線が再び使われ、該当する段は引き直されます。
4. 引き直し前の状態は「戻す」(Ctrl+Z)で戻せます。除外範囲は、作業ファイルとExcelに記録されます。

囲みきれずに文字の一部が残る場合は、もう一度、残った部分を囲んでください（除外範囲は複数指定できます）。

### 検証して引き直す（不自然な所を自動で見直す）

ツールバーの「検証して引き直す」(F7) または「検証」タブで、トレース線を点検し、不自然な所を引き直して、また点検します。

| 検証する項目 | 内容 |
|---|---|
| 画像の線から外れた区間 | 画像の線がない所を通る（推定接続は別扱い） |
| 経路の飛び | 隣り合う点の距離が大きい |
| 同じ区間を何度も往復 | 通常の戻りでは起きないほど多い場合だけ |
| 他の段の領域へ入り込む区間 | 隣の段の領域へ伸びる |
| 先端の取りこぼし | 画像の枝の先端に、経路が届いていない |
| 末端の未追跡 | 右側が途中で止まっている（引き直しの対象外。要確認として残す） |

- **対象の段と範囲の選び方**（「検証」タブ）: ① 対象の段＝「選択中の段」（右上の段の一覧で選んでいる段）／上段・中段・下段／全段、② 範囲＝「画面で範囲をドラッグして指定」（省略すると段の全体）、③ 最大回数を決めて実行。範囲を指定すると、その範囲の不自然な所だけを引き直し、範囲外が悪くなる引き直しは採用しません。
- 手順: 検証 → 不自然な所を、別の経路（または取りこぼした先端の追加）で引き直す → 再検証 → **点数が下がったときだけ採用**。
  下がらないときは元の線に戻します。最大回数（既定5回）まで、または改善がなくなるまで繰り返します。
- **引き直した結果は、採用・不採用を問わず消えません。**「検証」タブの履歴に、日時順に残り、選ぶと、引き直し前（灰色の点線）と後（緑＝採用／橙＝不採用）が画像に重なって表示されます。作業ファイルとExcelの「検証履歴」シートにも保存されます。
- 実行全体は「戻す」(Ctrl+Z)で一度に取り消せます（履歴は残ります）。
- 点数は不自然さの目安です。**不自然な点がないことは、正しいことの証明ではありません。**直せなかった箇所は、検証タブに残ります。

### 途切れの扱い（線がない所を無理につながない）

細い線が薄れて途切れている所は、**画像に薄い線の痕跡がある場合だけ**推定でつなぎ、黄色の破線で示します
（「要確認」にも長さ付きで出ます）。**紙が何も写っていない所には線を引きません**。その場合は、そこで追跡を止めて
「末端の未追跡」として示すので、手動で確認・修正してください。

- つなぐ条件: 途切れの区間の6割以上で、紙の地より暗い痕跡がある／ほぼ水平（急な傾きはつながない）／長さの上限（隣の端点まで120px、離れた断片まで300px）。
- ツールバーの「途切れを推定でつなぐ」をオフにすると、一切つなぎません（解析をやり直します）。
- 推定接続の区間上の頂点は、最大・最小と波の数から除外します。

### 記録方式の選び方（機種が分からないとき）

記録方式（インクペン・煤書き・光学など）によって、線の見え方や必要な処理が変わります。
機種が分からない図面では、**「方式を探す…」**（F6）を押すと、設定（プロファイル）を数種類順に試し、
重ね表示の縮小画像を横並びで表示します。元画像に重なって見えるものを選んでください。

| プロファイル | 想定 | 検証状況 |
|---|---|---|
| ① レバー式インクペン | 明るい紙に暗い線、大振幅が円弧状。時刻の刻み・小さな黒い印を除外 | サンプルB1-01のみ確認 |
| ② 明暗反転 | 暗い紙に明るい線（煤書きなど）。画像を反転して解析 | **未検証**（見本なし） |
| ③ 太い線・にじみ | 感光紙・光学など。弱い線も拾い、小さな欠けを埋める | **未検証**（見本なし） |
| ④ 汎用 | 方式が不明なときの標準設定 | サンプルB1-01のみ確認 |

- 候補に付く数値（末端まで追跡できた段数・未追跡の長さ・要確認の数）は、**うまくたどれたように見えるかの目安**で、正しさの保証ではありません。最終判断は画面で拡大して行ってください。
- 4種類の試行には、この環境（Linux）で約70秒かかりました（サンプル画像）。お使いのPCでは変わる可能性があります。
- 選んだ設定は作業ファイルとExcelに記録されます。ツールバーの「記録方式」でも、後から切り替えられます（解析をやり直します）。

### 区間測定（範囲を決めて、振れ幅・波の数・周期を調べる）

横軸が時間の記録では、時間の範囲を決め、その間の振れ幅（最大・最小）、波の数、周期を調べます。

1. 「区間を指定」(R) で、画像上を**横にドラッグ**（選択中の段に追加）。数値入力でも追加できます（「区間」タブ）。
   「全段に同じ範囲を追加する」で、三段同じ範囲を一度に追加できます。
2. 「区間」タブに、区間ごとの結果が出ます。区間は戻す（Ctrl+Z）・削除できます。
3. Excel の「区間測定」シートに出力されます。

| 項目 | 定義 |
|---|---|
| 最大・最小・上下幅 | 区間内の頂点から（0線を基準） |
| 山の数・谷の数・波の数 | 「数え方の設定」で選ぶ（山／谷／山と谷の平均）。隣の頂点との振れ幅が**数えない小さな揺れ[px]**未満の揺れは数えない（既定20px） |
| 平均周期 | 最初の山から最後の山までの距離 ÷（山の数−1）。山が2個未満のときは出さない |
| 周波数 | 1 ÷ 平均周期[s]（時間換算があるときだけ） |
| 除外した頂点 | 所属要確認の区間・推定接続の区間上の頂点は、最大・最小と波の数から除外し、件数を表示 |

**時間の与え方（資料がなくても設定できます）**: 「校正」タブで、次のどちらかを設定します。

- 紙送り速度[mm/s]＋X方向の校正（定規2点）
- 「時刻の刻み2点で時間を設定」: 画像上の時刻の刻みを2か所クリックし、その間の時間[秒]を入力

どちらも未設定のときは、周期は px 表示です（時間は出しません）。画面上の復元順の再生は、時間とはみなしません。

### 値を読む・円弧補正後との併記

- **値を読む**(V): トレース上をクリックすると、最も近いトレース上の点に吸着し、その点の値を**補正前と円弧補正後で並べて**記録します
  （X[px]・Y[px]・振幅・X[mm]・起点からの時間[s]、補正後X[mm]・補正後の時間[s]）。「読取」タブの一覧と、Excelの「読取点」シートに出力されます。
- **円弧補正後のトレース**: 校正タブでアーム長とX・Y校正を設定すると、補正後のトレースが**点線**で重なって表示されます
  （ツールバーの「円弧補正後」で切替）。Excelの「測定結果と画像」にも、元画像＋トレース＋補正後トレースの図を追加します。
- **区間測定**には、補正前の平均周期の隣に**円弧補正後の平均周期・周波数**を併記します。
- 画面下のカーソル位置には、校正があれば mm と振幅も表示します。

### 円弧補正（レバー式ペンの時間方向のずれ）

レバー（アーム）の先端で書くペンは、振幅が大きいほど、時間方向（X）の位置が円弧の分だけずれます。
「校正」タブで、**X・Yの校正**と**ペンアーム長[mm]**を入力すると、Excelに「円弧補正後のX[mm]」の列が追加されます
（さらに紙送り速度があれば「補正後Xからの時間[s]」）。ずれの向きは、記録機構によって異なるため利用者が選びます。
アーム長は推定せず、**入力がなければ補正しません**。補正式は `x' = x − 向き × (R − √(R² − a²))`（R: アーム長、a: 振幅[mm]）です。

### 大きな画像の表示（軽く表示する）

大きな画像でも拡大・縮小・移動が重くならないよう、**表示用には縮小した画像を用意し、ズームに合わせて切り替えます**
（拡大時は解析用の細かい画像、縮小時は1/2・1/4・1/8の軽い画像）。解析・測定・出力は、常に解析用の画像で行うので、
数値は表示の軽さの影響を受けません。元のファイルは変更せず、読み込み後の元画像は、メモリから手放します（必要なときは元のファイルを読み直します）。

### 画像エリアの幅を変える

- ツールバー（3段目）の**「画像エリアの幅」スライダー**で、画像エリアの幅を、ウィンドウの30〜90%の間で変えられます。
- 画像とパネルの**境目をマウスでドラッグ**しても変えられます（スライダーも連動します）。
- 「右パネル」(F4) で、右のパネルを隠すと、画像エリアがウィンドウいっぱいに広がります。もう一度押すと戻ります。
- パネルの幅の下限は約350pxです。ウィンドウの大きさと、パネルの配置は、終了時に記憶され、次回の起動で再現されます。

### 画面の構成

- 上: ツールバー（ファイル／編集／表示）。
- 中央: 元画像＋トレースの重ね表示。ホイールで拡大縮小、ドラッグで移動。
- 右: 段の一覧（色・表示切替）と、**測定／頂点／要確認／校正**のタブ。
- 最下部: 読込・解析・再追跡・保存の状態、読取確認の進み具合、カーソルの座標。

### 操作一覧

| 操作 | 方法 |
|---|---|
| 頂点の移動 | 「選択・移動」(S) で頂点をドラッグ。「線に沿って動かす」（既定オン）のときは、**画像の線の上だけを動き**、つながっていない別の線へは飛びません（つながりの届く範囲は、線に沿って約150px）。オフにすると自由に動かせます。または「頂点」タブで座標入力→「座標を反映」 |
| 頂点の削除 | 頂点を画像上でクリック（または「頂点」タブの一覧で選択）して、**Delete キー（Backspace でも可）**。ツールバーの「選択した点を削除」、「頂点」タブの「選んだ頂点を削除」でも可。削除した頂点は、一覧と、最大・最小・波の数・周期の計算から外れます（**線は変わりません**）。戻す(Ctrl+Z)で戻せます。選ばずに押したときは、その旨を表示します。選択中の点は黄（最後に選んだ点）／水色の大きな丸と「選択 #番号」で表示され、画像の左上に「選択中：N点（Delete で削除／Esc で選択解除）」が常に出ます。Esc で選択を解除できます。取り消しなどで頂点の並びが変わっても、選んだ点の座標を追いかけ、別の点を消さないようにしています。読取点・区間・除外範囲の一覧で行を選んでいるときは、Delete でその行を削除します |
| 頂点の追加 | 「頂点を追加」(A) で取り逃した先端をクリック。先端まで到達して折り返す経路が追加される |
| 再追跡 | 既定は移動後に自動。オフにすると保留され、「再追跡を適用」(Ctrl+Enter) で実行 |
| 修正の取消し | 「修正を取り消す」(Esc)＝未適用の修正を破棄 |
| 戻す／やり直す | Ctrl+Z / Ctrl+Y（段ごと）。「この段を初回結果へ」で段単位に初期化（他の段は変更しない） |
| 起点の指定 | 自動で起点が見つからない段で「起点を指定」(O)→波形の左端をクリック |
| 測定線 | 0線・上線・下線を上下にドラッグ（手動調整は「（手動）」と表示。「自動位置へ戻す」で復帰） |
| 校正 | 「校正」タブ。定規上の2点＋実距離、または数値入力。X・Y・紙送り速度・振幅係数 |
| 再生 | 「再生」(Space) で復元順に経路を再生。「頂点▶」「◀頂点」で頂点を順に移動 |
| 表示切替 | 元画像／トレース／頂点／測定線／要確認印、段ごとのチェック。頂点・弱い要確認印は拡大時のみ表示 |
| 図形を全部消す | ツールバーの「図形を全部消す」(H)。トレース・頂点・測定線・区間・印などをすべて**一時的に**隠し、元画像だけを表示。データは消えません。もう一度押すと戻る（保存はされません） |

修正が失敗した場合（指定位置の近くに画像の線がない、線がつながらない、など）は、理由を表示して**修正前の結果を保持**します。
未適用の修正がある間は、Excel・SVG の出力を止めます。

## 3. 出力

### Excel（.xlsx）

| シート | 内容 |
|---|---|
| 測定結果と画像 | 段別の測定値、0・上・下の高さ、線の調整状態、確認状態、換算条件、元画像と重ね表示画像 |
| 復元座標 | 段・復元順・X・Y・振幅・区分（自動取得／推定接続／手動頂点／再追跡）。経路は形を保つ範囲で間引き、頂点は必ず含む |
| 頂点と折返し | 頂点番号・座標・山/谷・往路/復路・折返しの種類・対応する復元順・由来・要確認事項 |
| 要確認 | 所属の曖昧さ、末端の未追跡、推定接続、他の段への逸脱、再追跡の失敗 |

「確認状態」が「確認済み」以外の値は**候補**です（確定した最大・最小値として扱わないでください）。

### その他

- **トレースのみ（SVG）**: 各段を1本の経路として出力。推定接続は破線。元画像を含めるか選べます。
  トレースのみでも、匿名化済みとは限りません。
- **作業ファイル（.trproj）**: 経路・頂点・測定線・校正・確認状態・手動修正・履歴を保存し、別の日に再開できます。
  元ファイルの識別情報（SHA-256）を持ち、**別の原本には適用できません**。

## 4. 座標と計算の定義

- 座標: 元画像の左上が原点、X は右向き、Y は下向き（px）。解析は縮小画像で行い、出力は元画像の座標へ戻します。
- 振幅: `a = y0 − y`（0線より上が正）。y0 は各段の起点付近の高さ。
- 最大値・最小値: 頂点の a の最大・最小。位置（X・Y）を対で出力。
- 上振幅 = max(0, 最大値)、下振幅 = max(0, −最小値)、上下幅 = 最大値 − 最小値。
- 「連続する頂点間の最大差」は**参考値**として別に出力（要確認事項①）。
- 他の段の領域へ伸びる区間上の頂点は、最大・最小の対象から外し、件数を表示します。
- 未校正では px 表示。校正すると mm、さらに振幅係数を設定するとその単位で表示。紙送り速度の設定がない限り時間は出力しません。

## 5. 仮置きした事項（要件定義書の「要確認」）

| 事項 | 今回の仮置き |
|---|---|
| ① 最大差 | 上下幅（最大値−最小値）を主、連続頂点間の最大差を参考列 |
| ② 測定範囲 | 段全体 |
| ③ 換算条件 | 未校正は px。校正は利用者入力 |
| ④ 許容誤差・評価原稿 | 未設定（正解データが未提供）。試験は合成シートで実施 |
| ⑤ Windows版・配布方法 | Windows 10/11 64bit、PyInstaller の onedir 形式（フォルダ配布） |
| ⑥ 画像のない位置の手動点 | 対象外 |
| ⑦ 記録方式 | 利用者が選ぶ。不明なときは「方式を探す」で数種類を試して選ぶ（自動判定はしない） |

## 6. 既知の制限

- 自動読取の精度は未達（頂点の取りこぼし、隣の段・汚れへの迷い込み、細線が切れた先の未追跡）。
- ②③の記録方式プロファイルは、見本がないため未検証。円弧補正の向き・アーム長は利用者入力に依存。
- 傾き補正・回転補正は未実装（変換情報の保存枠のみ）。複数ページの一括処理、三段以外の本数も対象外。
- Windows 実機での動作・Excel の実機表示は未確認。

## 7. 開発者向け

```
traceview/
  imageio.py     読込（PDF/画像、原本は変更しない）
  preprocess.py  紙領域・定規・基準線・注記の除外、インク抽出
  graph.py       骨格 → グラフ（端点・分岐・辺）、途切れの補修
  tracer.py      ペンの経路をたどる（先端へ到達→折返し、往復、分岐の判断）
  vertices.py    経路に沿った山・谷の抽出
  engine.py      解析全体、頂点の移動・追加と再追跡、戻す／やり直す
  measure.py     測定値・校正
  project.py     作業ファイル  excel_out.py / svg_out.py  出力
  profiles.py    記録方式プロファイル（設定の組）
  gui/           PySide6 の画面（方式の比較画面を含む）
tests/           合成シートを使った試験（python -m pytest tests）
```

試験の限界: 合成シートでの合格は、実データの精度合格を意味しません。実データでは正解の頂点・所属を基準に別途評価してください。


### 急な線の薄れ
急な角度の細い線（大きな振れの線）の墨が薄れても、定規の線の下を除いて墨が見える間は、同じ向きに先端まで追います。延ばした部分は「推定でつないだ線」として印が付きます。
